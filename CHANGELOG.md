# Changelog

All notable changes to this theme will be documented in this file.

## [1.0.0] - 2026-04-10

### Added
- Retro 80s synthwave aesthetic with neon colors (pink, cyan, purple, orange)
- Animated hero section with retro sun, perspective grid, and city skyline
- Customizable logo (text or image)
- Google Fonts integration (Orbitron & Share Tech Mono)
- Custom scrollbar and form styling with neon effects
- Background music support with play button and persistent playback across page navigation (AJAX-enabled)
- Fully responsive design
- Mobile support with fade-in menu and scale animation
- Quark-compatible page templates (Default, Item, Blog, Error, Modular)
- Custom contact page with retro fax modem styling
- Animated footer with heartbeat effect
- VHS effect with scanlines, noise, flicker, and chromatic aberration
- Admin panel configuration options:
  - Production mode toggle
  - Site name field
  - Enable logo image toggle with file upload
  - Background music file selection (stored in songs/ folder)
  - Hide play button toggle
  - Enable AJAX navigation toggle (enabled by default)
  - Enable VHS effect toggle (disabled by default)
- Full theme translations (EN, DE, FR)
- Lightbox feature for images (use ?lightbox in links)
- Theme page with documentation and usage guide
